# Thư mục Slide Thuyết trình

Thư mục này dùng để lưu trữ file slide thuyết trình bảo vệ đề tài:
- Tên file: `Slide_Thuyet_trinh_[Tên_Nhom].pdf`
- Độ dài: 12 – 15 trang (slide).
- Nội dung: Súc tích, trực quan, thể hiện bối cảnh, EDA, kiến trúc Pipeline, bảng so sánh đa chỉ số, kết quả demo và đóng góp của các thành viên.
