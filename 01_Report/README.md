# Thư mục Báo cáo Kỹ thuật (Technical Report)

Thư mục này dùng để lưu trữ file báo cáo kỹ thuật chính thức của nhóm theo quy cách:
- Tên file: `Bao_cao_BTL_[Tên_Nhom].pdf`
- Độ dài: 15 – 25 trang A4 (không kể phụ lục và tài liệu tham khảo), font Times New Roman cỡ 13, giãn dòng 1.3 – 1.5.
- Cấu trúc:
  - Trang bìa & Bảng phân công công việc (Họ tên, MSV, vai trò, % đóng góp, chữ ký).
  - Chương 1: Giới thiệu bài toán & Mục tiêu nghiên cứu.
  - Chương 2: Khám phá Dữ liệu (EDA) & Tiền xử lý.
  - Chương 3: Cơ sở Thuật toán & Thiết kế Pipeline.
  - Chương 4: Kết quả Thực nghiệm & Đánh giá Mô hình.
  - Chương 5: Kết luận & Hướng phát triển.
  - Tài liệu tham khảo.
